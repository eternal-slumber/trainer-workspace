## Границы проверки

Ответы модели подставляет HTTP-стенд. Просроченные lease и durable response
для проверки живого scheduler подготовлены напрямую в отдельной БД; это
не аварийное завершение настоящего провайдера. Реальные отдельные PHP-процессы,
crash до отправки/после отправки/после checkpoint, late worker, параллельное
резервирование и rollback публикации покрыты существующими PostgreSQL/Pest
тестами с искусственным AI-клиентом. Их последний полный результат:
341 passed, 4 skipped, 2257 assertions. На этом шаге production-код не менялся,
поэтому полный набор повторно не запускался.

После визуальной проверки основного pipeline, failed и uncertain компьютерное
управление потеряло окно Safari (`cgWindowNotFound`). Нажатие кнопки закрытия
uncertain в браузере и UI после этого закрытия остаются ручной проверкой;
сам endpoint и его обязательное подтверждение проверены настоящими HTTP-запросами.

## Вывод для пилота

Блокирующих дефектов приложения в выполненных сценариях не обнаружено.
Для пилота нужно задать ключ провайдера и выполнить один реальный запрос,
проверив качество/валидность ответа и описанное закрытие uncertain в интерфейсе.
Текущая локальная конфигурация без ключа к настоящей генерации не готова.

`composer run dev` запускает обычную очередь default и не запускает scheduler.
Для этого pipeline обязательны отдельный worker выделенной очереди и scheduler;
команды приведены в [документации этапа 2](training-plan-generation-stage-2.md).
Не считать успешный запуск веб-сервера подтверждением работы этих процессов.

Не проверены длительный простой, большой backlog, нагрузка и production supervisor.
Recovery допускает дубли Job; они обработаны без дублей плана/LLM, но при долгом
простое требуется контролировать размер очереди. Общая атомарность контекста
без синхронизации независимых writers по-прежнему не гарантируется.

После проверки временные app/worker/scheduler/HTTP-стенд остановлены.
Изолированная БД с синтетическими данными сохранена для повторного просмотра;
скрипты и технические логи лежат вне репозитория в `/private/tmp/trainer-pipeline-e2e`.
Коммит и push на момент составления отчёта не выполнялись.
